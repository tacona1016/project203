# Chart and review rules

Use horizontal bars for single-choice counts and multiple-choice selection rates. Keep identical scale across options and display count plus percentage. Scores use a 0–4 axis (allowed responses1–4); show n, mean, median, min/max, population SD and distribution table. Label ties with competition ranking and never hide zero values.

Count each person once per option and once in participation. A 200% sum for two-choice polls is expected; a single-choice total different from respondent count is an error. Use a fixed server timestamp and respect actual end times plus results_visibility. Keep denominator changes explicit.

For four-score allocations, accept exactly four score values1–4 summing10. A complete explicit list with unique item labels1–4 (for example four lines using 1. / 2. / 3. / 4. followed by whitespace and a score) separates question numbers from values; preserve item order, not incidental line order. Do not strip arbitrary extra numbers, guess missing values, or repair decimal/out-of-range/sum errors. Validate SQL stats independently from aggregate distributions. Use user-confirmed meanings when supplied; temporary position labels must not imply meanings from another deck.

Review checklist: original slides preserved, graphics and sources intact, no personal response export, no public result route/data, scoped theme only, six layout types covered, mobile and presentation screens inspected, keyboard/TOC/fullscreen work, long content can scroll, fallback fonts checked. Record measured checks separately from untested real-member E2E.
