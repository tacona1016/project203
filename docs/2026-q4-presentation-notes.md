# 2026 Q4 발표자료 작성 기준

## 범위와 자산

- 본문은 12개 `Slide`이며 댓글은 번호 없는 별도 섹션이다.
- `public/images/2026-q4/`의 새 SVG 13개는 이 발표자료를 위해 직접 제작했다. 외부 사진이나 유료 이미지는 포함하지 않았다.
- 지도·필지·단면·비용 그림은 설명용 개념도다. 실제 후보지, 측량값, 이동시간, 공사비 비중을 나타내지 않는다.
- 마지막 점수 보드는 선호 공유용 정적 설명이다. 값을 입력하거나 서버에 저장하지 않는다.

## 비용 가정

확인 기준: 2026-10-23. 현재 가격 수준의 **기획용 예산 가정**이며 전국 평균, 업체 견적, 미래 공사비 예측이 아니다.

| 단계 | 발표자료의 범위 | 전제와 별도 항목 |
| --- | --- | --- |
| 토지 구매 | 토지대금 3억 원 이하 | 약 200평(약 661㎡)을 찾는 예산 필터. 취득 비용 별도. 해당 조건의 매물 존재를 보장하지 않음 |
| 대지 조성·인프라 | 약 0.3–1억 원+ | 필지 미정 단계의 예비 가정. 외부 토목·인입 기준. 옹벽·경사·진입로·장거리 인입이면 초과 가능 |
| 건축 본체 | 약 2.5–4.5억 원+ | 연면적 30–40평·일반 사양. 건물 기초·구조·내부 설비 중심. 설계·인허가·감리·외부 공사·조경·가구·세금 별도 확인 |

건축 범위는 아래 건축사 사무소의 구조·사양별 평당 공사비 설명을 참고해 여유를 둔 **작성자의 계획 범위**다. 출처가 2.5–4.5억 원을 직접 제시한 것은 아니다. 토목 범위도 개별 필지 견적을 대신하지 않는다. 부가세와 외부 공사의 포함 여부는 실제 견적서에 명시한다.

Phase 2의 대지 조성과 Phase 3의 건물 기초를 중복 산정하지 않는다. 2030·2035년에는 물가와 조건이 달라질 수 있으므로 토지 계약 전, 설계 전, 착공 전에 재산정한다. 토지 활용과 공동소유·운영 합의도 계약 전에 별도로 검토한다.
