## 비공개 데이터 처리

공개 저장소에 실제 결과 JSON·개별 원문·회원 UUID·사진·QA 스크린샷을 커밋하지 않는다. `lib/presentation/survey-data.ts`는 회원 세션을 요구하는 서버 전용 조회다.

1. 기존 `get_poll_catalog(p_include_hidden=false)`로 정확히 ID 1,9,10,11,12,13,14의 결과 공개 조건을 확인한다.
2. 선택지 문구를 한 번에 읽고, ID11은 `get_poll_detail(p_admin=false)`에서 공개된 응답만 서버 안에서 집계한다.
3. 카탈로그와 공개 정책을 재확인한다. 숨김·재개·설정 변경 또는 누락이 있으면 요약 전체를 표시하지 않는다.
4. 등록 회원 수를 분모로 사용한다. 객관식은 기존 RPC의 canonical 선택 집계를 재사용한다. 텍스트는 정수1~4 네 개·합계10을 검증한다.
5. 서버 시각과 집계값만 HTML로 출력한다. 원문·다른 회원의 신원은 전달하지 않는다. 정상 0명과 조회 실패·공개 보류를 구분한다.

기존 투표 저장·결과 공개 RPC, RLS 및 Private Storage는 수정하지 않는다. 새 migration 및 환경변수도 없다. 한 요청에서 필요한 DB 조회는 카탈로그 2회, 등록 인원 HEAD 1회, 선택지 배치 1회, 주관식 상세 1회다. 게시글/투표 수에 따른 N+1 조회는 없다.
